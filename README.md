### Data analysis, Power BI dashboards & automation

I turn manual spreadsheet work into **reliable reports, dashboards and workflows** —

#### What I can help with

- **Power BI dashboards** — star-schema models, DAX measures and clear report pages, with every number checked against an independent reference
- **Automated reporting** — from raw sales or operations data to a ready-to-share report in one command
- **Data cleaning & analysis** — messy files in, consistent numbers and clear insights out
- **Process automation** — repetitive file and spreadsheet routines replaced by scripts you can trust
